# Code 연습용

이 저장소는 GitHub Pull Request 워크플로우를 연습하기 위한 저장소입니다.

## 목적

- 브랜치 생성
- 커밋 및 푸시
- Pull Request 오픈

이 저장소를 통해 기본적인 Git/GitHub 협업 워크플로우를 익히는 것이 목표입니다.

## 사용법

1. 저장소를 클론합니다.
   ```bash
   git clone https://github.com/kakalee91/claude-code-practice.git
   ```
2. 새 브랜치를 만듭니다.
   ```bash
   git checkout -b my-branch
   ```
3. 변경 사항을 커밋하고 푸시합니다.
   ```bash
   git add .
   git commit -m "설명"
   git push -u origin my-branch
   ```
4. GitHub에서 Pull Request를 엽니다.
